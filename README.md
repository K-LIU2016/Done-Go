# 探戈 Done&Go

**事情搞定，时间归你。**

探戈帮助你记录事项、确定优先级，并在完成后看见实际腾出的时间。散步、陪家人、学习，或自由安排，由你选择。

唯一的当前产品入口是无需构建的 Done&Go 网页应用：`http://localhost:5207/#today`。它由 `web/index.html` 和 `scripts/serve-tango.mjs` 提供，五个 hash 路由（`#today`、`#line`、`#review`、`#agreements`、`#settings`）共同组成同一个探戈 Done&Go。

仓库中的 React/Vite、`src/`、`server/` 和 `/inbox` 文件继续保留，作为历史实验与后续研究资料；它们不代表当前产品入口或上线标准。当前产品架构见 [唯一产品架构](docs/DONEGO-CANONICAL-ARCHITECTURE-2026-10-16.md)。

## 页面

- **今天**：清醒预算、全天未安排、已安排和个人预留时间；输入或语音记录事项，形成可编辑的事项池，按优先级查看和完成。
- **时间之树**：按日期查看安排、原计划区间与完成状态。连续工作时保留眼睛、肩背和饮水提醒。
- **回顾**：按同一组 7 / 30 天日期统计已确认腾出的分钟和实际用到的个人时间；日历记录时间收益，不评价用户的分数或连续打卡。
- **约定**：本地双角色演示；双方确认相同版本后形成约定，执行权限仍需单独授权。
- **设置**：版本、服务状态、本地数据边界、AI 发送设置、备份恢复和证据导出。

## AI 是事项旁的一项帮助

对于阅读论文、写作修改、邮件、会议纪要等具体事项，提供小型「查看模型能力」入口，展示：

- 公司、参考型号、主要能力，以及官方应用和模型说明链接。
- 适合电脑或手机的使用方式。
- 可复制的具体提问和核对步骤。
- 有至少两次同类、已验收 AI 使用记录时，提供个人历史差值区间；记录不足时显示「待实测」。

参考型号不表示应用当前默认型号，也不承诺额度或价格。查看推荐不会缩短事项，也不会生成已确认收益。

## 完成 → 确认 → 时间归你

例如，09:00–10:00 的事项完成后，填写实际用时 40 min（包括准备、核对与返工），并注明是否使用 AI：

```text
腾出 20 min
09:40–10:00
散步 · 自由安排 · 另选
```

这时仅生成一个持久保存的待选项。选择用途后才会预留；与已有事项冲突时继续由用户决定。原时段已开始或过去时，需要另选未来时段。

预留时间结束后，再确认是否用到了。回顾区分「腾出时间」与「用到自己的时间」；计划与实际的差值不等于 AI 的因果贡献。

## 本地使用与验证

启动当前产品的本地服务：

```sh
node scripts/serve-tango.mjs
```

访问 `http://localhost:5207/#today`。服务监听 `127.0.0.1:5207`，提供静态页面和可选语音 API；核心事项、时间收益和回顾仍可在没有语音或外部模型时运行。

也可以使用：

`npm run start:web`

```sh
npm ci --ignore-scripts
node --test tests/unit/tango-time.test.mjs
npx playwright test --config playwright.tango.config.ts
npm run lint
npm run build
```

独立浏览器配置在 Windows 使用已安装的 Edge，其他平台使用 Playwright Chromium，也可通过 `TANGO_BROWSER` 指定。浏览器测试覆盖桌面和手机、时间计算、完成确认、用途选择、冲突取消、持久化、键盘焦点、主题及语言导航。

`npm run build` 和 `npm run build:web` 生成当前产品的独立交付目录 `dist-web/donego-*`，包含实际网页、Node 启动脚本和 SHA-256 文件清单。每次生成新目录，保留旧交付包供回退；启动无需安装依赖。历史 React 工程通过 `npm run build:react-history` 单独构建。

发布检查使用 `npm run verify:web` 和 `npm run verify:ui`。首轮实测流程、指标定义与回退方式见 [用户实测包](docs/USER-TEST-STARTER-2026-10-16.md)。

## 数据与边界

- 数据保存在当前浏览器，可导入、导出。保留原有存储键和导入兼容性，不主动清除已有记录。
- 全天未安排 = 清醒预算 − 当天全部安排的区间并集。重叠分钟只扣一次；它不是从当前时间到睡前的空闲倒计时。
- 回顾差值 = 已验收任务的计划 − 实际总用时；保留负值，按事项与日期去重，不计旧的未验收估计记录。单个任务只有正差值才提供可预留时间。
- 个人历史区间是少量历史记录的观察范围，不是人群平均阅读时间、预测保证或 AI 效果实验。
- 当前用时记录沿事项的计划起点标记时间范围；跨午夜的实际耗时保留在完成记录中，时间线在当日午夜截断。
- 语音需要浏览器支持与麦克风权限；自定义 AI 接口需要用户配置。模型入口只提供指导，不会代用户上传文件。
- GitHub 源码同步与部署是不同操作。多用户账户、跨设备同步、支付及公开部署不在本轮交付范围内。
