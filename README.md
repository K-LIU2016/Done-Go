# Done&Go（探戈）

> **事情搞定，时间归你。**

**Done&Go (Tango)** is a local-first time instrument for the AGI era. Say one sentence about your day; AI structures it into items, shows you exactly which models can help and how, measures honestly whether time was actually saved — and hands the freed time straight back to you. Built for students, researchers, teachers, and office workers who suspect their time is worth more than repetitive operations. *探戈：一句话开始今天，事项与模型能力一清二楚，腾出的时间当场归还给你。*

界面语言：中文 · English · Русский · ไทย · العربية · 한국어

---

## 为什么是探戈 · Why Tango

有生之年，我们都在与时间共舞——或孤独、或喧嚣、或悲伤、或欢欣。AI 发展得太快，快到很多人还只是在用豆包的时候，AGI 时代就到了。这支舞，值得有人陪你跳。

Done&Go 想回答四个问题：

1. **时间去哪儿了？** 给高校学生、研究员、老师和公司职工一个诚实的时间去向可视化工具——预算、已排、预留、腾出，每个数字都有计算口径。
2. **AI 到底省不省时间？** 弥合学术环境与 AI 发展之间的鸿沟：每个事项都可记录「使用 AI 前后」的真实用时，差值只在结果核验后才计入收益。时间，不必再被反复的操作浪费——但这个判断由你自己的数据做出，而不是广告词。
3. **只会用豆包的人，去哪儿练 AI？** 这是一个 AGI 时代的 AI 试炼场：针对每一件事，每个模型的能力、出处与适用场景一清二楚；在知道能力的前提下提供模型优先级选择，并给出可直接复制的提示词。在生活的点点滴滴里，把 AI 用明白。
4. **AI 时代的习惯长什么样？** 帮助人们养成「先看能力、再给授权、事后核验、腾出时间留给自己」的习惯——帮助更多的人成为 AI Native。

## 设计理念 · Design Principles

### 贴合 · Fits Real Life

- **一句话开始**：`14:00-15:00 写论文文献综述，15:30 回复导师邮件`——语音或文字随口一说，AI 整理成带时间、优先级（最优先→不急五档）与类别（创造 / 必要……）的事项，你确认后才记下。
- **留给自己 · 每格 30 min**：拉伸、陪家人、看月亮、好梦、星空……完成事项腾出的时间，配得上一个诗意的去处。
- **莫奈日历**：腾出时间的日历有七款配色——睡莲、日出印象、干草堆、撑阳伞的女人、吉维尼花园、鲁昂大教堂、雾中国会。
- **六种语言**：中文、English、Русский、ไทย、العربية、한국어——一如这支舞本来的样子。

### 求真 · Nothing Unverified

- **待实测 · 不承诺节省时间**：每个模型建议都标注任务级效果未实测；你的地区、账户与可用性需要自己核验，界面明说。
- **结果验收三态**：待核验（暂不计入收益）／已核验（结果可用）／需返工（暂不计入收益）。没核验过的节省，不算节省。
- **总用时 = 执行 + 准备 + 核对 + 返工**：一次填清，不许重复计算——用 AI 省下的十分钟，不该被反复核对的半小时吃掉而无人知晓。
- **能力来源可查**：模型能力来自官方文档，标注资料核验日期；给出「打开应用」与「官方能力说明」双链接；失败时回退备选或人工流程；上传前提醒移除身份信息与密钥。
- **每个数字有口径**：预算、已排、预留、差值均可查看计算方式；计算占用时按区间并集合并重叠分钟。

### 本质 · Time Is Not a Container

时间不是等待被填满的容器。完成事项的那一刻，省下的时间**当场归还**：散步、自由安排、另选时段，或稍后决定——去处由你定，探戈只负责把时间递还到你手上。「什么也不安排」也是一个合法结果；留白不是缺失，而是被保护的自主空间。

### 深度 · From Tool to Habit

探戈不止记录时间，它长出你的**个人历史参考**：差值统计会诚实地说「样本不足」，也会在你积累之后告诉你——不靠 AI，这件事通常要多久；借助 AI，实际花了多久。当「先看能力、再给授权、事后核验」成为肌肉记忆，你就是 AI Native。

## 产品地图 · The Product

### 今天 `#today` — 一句话，开始今天

| 环节 | 你看到什么 |
| --- | --- |
| 录入 | 语音记录 / 说或写事项 → **整理**（AI 解析时间与事项） |
| 事项卡 | 时间 · 优先级五档 · 类别 · ✦ 查看模型能力 · 记下 |
| 模型能力面板 | 主推模型（如 Claude Sonnet 5.5）+ 备选（GPT-5.4、Gemini 3.1 Pro）· 官方能力说明 · **怎么用**三步 · **可复制的提示词** · 诚实免责 |
| 完成 · 记录用时 | 执行 / 准备 / 核对 / 返工分项 · ☑ 使用了 AI · 结果验收三态 |
| 腾出时间 | 散步 / 自由安排 / 另选 / 稍后决定（并注明：不代表全部由 AI 带来） |
| 留给自己 | 30 分钟一格：拉伸 · 晚饭 · 陪家人 · 遛狗 · 看月亮 · 星空…… |
| 今日时间 | 预算（按你设定的清醒小时数）· 已排 · 预留 · ⓘ 口径 |

### 时间之树 `#line` — 一天一棵树

待办是**花朵**，临近一小时陆续开放；完成即结成**果子**；带 ✦ 的果子意味着这一程有 AI 同行。树随日出日落（本地实测时刻）与小时轴生长，逐日可回看。临近 1 h 开花 · 完成结果 · 记录保留。

### 回顾 `#review` — 如实核算

- **时间差值**：7 / 30 天 · 个人历史参考（样本不足会声明）· 已验收差值（原计划 − 实际）
- **腾出时间记录**：周历视图，莫奈配色七款
- **时间去向**：按类别累计（创造 45 min · 必要 30 min ……）
- **AI 辅助机会**：针对尚未完成的具体事项给出一句话建议与能力入口（「起草回复，由你确认」）
- **时间归你**：预留之后确认是否真用到了，让回顾反映真实收益

### 和探戈聊聊 `#assistant`

点击发送直接提问，普通聊天逐段显示模型回复。模型由服务端配置，按聊天、建议与测试用途选择档位。隐私选项和链接记录收在可展开入口；涉及事项改动的建议仍需本人采纳。

### 设置 `#settings`

称呼 · 每天清醒几小时（时间预算基准）· 提示音 · 服务端 AI 端点、模型档位与推理强度 · 时间记录的 AI 授权 · 导入 / 导出 / 示例 / 清空。

**事项与对话历史保存在当前浏览器。** 使用 AI 时，本次问题和用户选择共享的上下文会经服务端发送给配置的模型服务。API 密钥仅在服务端读取，不进入浏览器或数据导出。

## 边界与诚实 · Boundaries

- AI 整理的结果，经你确认才记下。
- AI 辅助默认「待实测」，收益未核验不计入。
- 完成与验收分离，腾出的时间要你亲手决定去向。
- 能力描述来自官方文档，效果由你的数据说话。
- 没有用途的时间，不需要被系统强行填充。

## 技术与运行 · Tech & Run

- **当前产品栈**：`web/index.html` 与独立 JavaScript 模块，Node.js 本地服务；入口为 `http://localhost:5207/#today`。`src/` 中的 React / TypeScript / Vite 工程作为历史资料保留，不是当前运行入口。
- **质量**：Playwright 端到端测试（`tests/`）；`docs/` 内含 PRD 与设计附录；`design/` 内含高保真设计稿与页面索引
- **部署**：支持 Docker（`Dockerfile` / `deploy/`）

```bash
npm ci --ignore-scripts
npm run dev        # http://localhost:5207/#today
npm run verify:web # 当前产品单元与边界验证
npm run verify:ui  # 桌面和手机浏览器回归
npm run build      # 输出独立交付包 dist-web/donego-*
```

## 从新副本运行

使用 Node.js 22 或更高版本。复制 `.env.example` 为本机 `.env`，填入服务端 AI 密钥；也可沿用 `.tango-donego/assistant.json` 指定的环境变量。两类私密文件均不上传 GitHub。启动服务后，在 `#settings` 核对接口和模型。未配置 AI 时仍能查看本地事项，聊天会明确提示连接不可用。

`npm run build` 生成网页、启动脚本和 SHA-256 清单；无需下载模型权重。Windows 浏览器回归默认使用 Edge，其他平台需准备 Playwright Chromium。真实模型验收须显式设置 `TANGO_LIVE_AI=1`，常规回归使用合成数据和受控响应，不产生模型费用。
