# 探戈 · 同频（社交游戏化）PRD

定稿：Claude（Done-Go CEO / CTO，JC 授权全权决策）· 2026-10-25
分支：`feat/social-sync` · 原型：`design/social-sync/prototype.html` · 总览图：`social-board.png`

## 0. 一句话
**把"接力"从人和 AI 之间，延伸到人和人之间**：你学会的 AI 用法可以传给同频的人，对方学会了，你就"传棒"成功。每周根据你怎样用 AI 优化日程、怎样分配空出来的时间，给出你的**时间流派**，帮你找到**同频的人**，结成**接力搭档**和**同频圈**。

## 1. 为什么这样设计（调研依据）
| 发现 | 来源 | 落到设计 |
|---|---|---|
| 头几周点过赞、加过俱乐部的用户，半年留存是其他人的 2 倍以上（公司自报，相关性） | Strava | 首周引导：给 1 个人加油、加入 1 个圈；加油做到一键完成 |
| 收到的鼓励越多，活跃度越高（观察研究） | Radboud 跑团研究 | 每次毕业、每次分配空出时间都可以被加油 |
| 双人互相监督有效，好友位设上限 | Duolingo 好友连胜 | 接力搭档最多 5 位 |
| 好友圈规模和活跃度正相关；**向上比较正向、向下比较负向** | 微信运动研究 | 不做全站时长排行；只展示"比你稍多一点"的同频者；圈内比较用接力和传棒，不比工作时长 |
| 用"收听流派"给人分组，加上和朋友的多人对比 | Spotify Wrapped 2025 Clubs | 6 种时间流派，以及"和搭档对比本周" |
| 数据不准会引发信任危机 | 网易云 2025 年报争议 | 每个数字都可以看口径；"同频理由"必须来自真实数据 |

## 2. 用户与场景
- 大学生、研究生：同一个课题组、同一门课的同学结成圈；"组会前一晚大家都在用 AI 整理文献"。
- 中小学老师：同一个教研组；传棒"写评语"、"出题"的用法。
- 职场新人：同一批入职的同事；互相传"周报"、"会议纪要"的用法。
- 长辈：子女把"看懂体检单"的用法传给父母。这是**最温暖的一次传棒**。

## 3. 核心概念与数据
### 3.1 每周 AI 原生画像（客户端在本地计算，只上传聚合值）
```
features = {
  week: "2026-W43",
  kindMix:  {necessary, create, connect, explore, restore, stillness}  // 事项类别占比（总和为 1）
  rhythm:   {dawn, morning, afternoon, evening, night}                 // 事项开始时段占比
  usages:   ["meeting-notes", "paper-5points", …]                      // 本周用过的用法 id（只有 id）
  relays: 9, graduations: 3,
  rating:   {much, little, none},                                      // 用户自评次数
  freedTo:  {family, exercise, study, rest, hobby, other}              // 空出来的时间去向占比（来自用户确认的预留或使用）
  freedMinutesConfirmed: 180                                           // 只算本人确认过的
}
```
**绝不上传**：事项标题、材料、AI 结果、具体时间、地点。

### 3.2 时间流派（6 种，每周计算，规则可解释）
| 流派 | 判定要点（示意，ZCode 要做成可配置阈值并写 unit） | 颜色 |
|---|---|---|
| 晨光整理派 | morning 与 dawn 占比 ≥ 50%，并且整理类用法多 | #E8B04B |
| 深夜创作派 | night 与 evening 占比 ≥ 45%，并且 create 占比高 | #4C7A93 |
| 接力达人派 | relays ≥ 8，并且 graduations ≥ 2 | #E95432 |
| 生活慢行派 | freedTo 中 family、rest、exercise 合计 ≥ 60% | #3E7B5B |
| 学术攀登派 | 论文、文献、阅读类用法占主导 | #615CED |
| 多线并行派 | kindMix 的熵最高、事项多 | #C7701F |
每种流派有吉祥物插画（探戈机器人的变体）、一句话描述和"本周证据"三条。

### 3.3 同频匹配
- 只在**主动开启"同频"**的用户之间匹配；身份是**化名 + 头像色**，不展示真实姓名或邮箱。
- 相似度是加权余弦：kindMix 0.3、rhythm 0.2、usages 的 Jaccard 0.3、freedTo 0.2。每周推荐 3 位，**只推荐"略多一点"的人**：对方的 graduations 不少于你，但不超过你的 2 倍加 2。
- **同频理由**必须由真实特征生成，最多 2 条，并且粗粒度。例如："你们都在晚上 10 点后做创作类的事"、"你们都把空出来的时间给了运动"。
- 冷启动：同频池不足 3 人时，推荐自己所在圈的成员；仍不足就显示"邀请同学加入，一起找同频"，**不造假人**。

## 4. 功能（MVP 全做，按此顺序）
1. **流派卡**（同频首页顶部）：本周流派、吉祥物、三条证据、"生成分享图"。
2. **同频推荐**：3 张卡，包括化名、流派、相似度、同频理由、TA 最近学会的 2 个用法，按钮"加油"和"结为搭档"。
3. **加油**（kudos）：可以对搭档或圈友的事件加油，例如"学会了一个用法"、"自己做到了"、"把 30 分钟给了家人"（这些事件只在本人确认分享后出现）。加油一键完成，被加油的人会收到轻提醒。
4. **传棒（用法交换）**：在"我的用法"任何一个用法上点"传给 TA"，选择搭档、圈或生成链接；对方会收到一张用法卡，只含场景和提示词模板，**不含任何个人内容**。对方完成接力或毕业后，发送者的"传棒"加 1，双方都看得到传递链（"这个用法经过了 3 个人"）。
5. **接力搭档**（双人连续接力）：两个人每天各完成 ≥1 次 AI 接力，共享一个火苗计数；每周有 1 次冻结；最多 5 位搭档；一方断了只提醒，不惩罚。
6. **同频圈**：课题组、班级、教研组、团队，邀请码加入，规模 3–50 人。圈主页展示：
   - 本周圈内"学会的用法"墙；
   - 传棒链；
   - 圈挑战进度；
   - "空出来的时间"去向汇总（只显示占比，不显示个人）。
   **不做个人工时排名**；圈内排名只按传棒数和毕业数，并且只显示前 3 名和"你"。
7. **周挑战**：每周 3 个，个人和圈级，例如"用 AI 完成 3 件生活小事"、"把空出来的 1 小时给家人并确认"、"给 1 个人传棒"。完成后得徽章，徽章进入"我的用法"。
8. **邀请增长环**：访客或新用户可以看到同频的预览（模糊处理）；"邀请 1 个同学，一起开启同频"；传棒链接打开后能直接试这个用法（访客可用），试完再引导注册。

## 5. 隐私与安全（硬性）
- 同频默认**关闭**，开启前一屏讲清楚会分享什么（仅聚合特征和你选择分享的事件）；可以随时关闭并删除服务端数据（24 小时内完成）。
- 化名系统：随机生成"形容词 + 自然物"，可以修改；屏蔽、举报、退出圈；圈主可以移除成员。
- 未满 18 岁（注册时自报）只允许加入有邀请码的圈，不进入公开同频池。
- 服务端只存聚合特征、关系和事件计数；存储做最小化；接口按账号鉴权，并做限流。
- 不做私信聊天（MVP 的范围和风险控制）：互动只有加油、传棒和搭档。

## 6. 信息架构与界面（见原型）
- 新增第 4 个 tab "同频"（图标为两个人）：**流派卡 → 本周同频 3 人 → 我的搭档 → 我的圈 → 周挑战**。
- 在"我的用法"的用法卡上加"传给 TA"；在结果页的毕业瞬间加"分享这次毕业"（可选）。
- 新用户首次进入的引导（3 屏）：同频是什么、会分享什么、开启。

## 7. 后端
- 新文件 `scripts/social-store.mjs`（SQLite，沿用 collaboration.sqlite 所在目录，新库 `social.sqlite`，权限 600）。表：`profiles_weekly`、`pairs`、`kudos`、`baton_shares`、`baton_events`、`circles`、`circle_members`、`quests`、`quest_progress`、`blocks`、`reports`。
- 新文件 `scripts/social-service.mjs`：REST 接口 `/api/social/*`（opt-in、upload-profile、matches、kudos、baton、pairs、circles、quests、report/block、delete-me），全部需要登录鉴权（访客只能调 preview），并做限流。
- 匹配是每周批量加实时增量，候选池按周分区。
- 集成到 `serve-tango.mjs` 只需要一行挂载，放在第二阶段的集成节点做。

## 8. 指标
- 北极星：**每周传棒成功次数**，即传出的用法被对方完成接力。
- 次要：开启同频率；首周加油 ≥1 的比例（对标 Strava）；搭档火苗 7 日存活率；圈周活；邀请转化率。
- 保护指标：屏蔽和举报率；关闭同频率；"压力感"反馈（周挑战里给一个"太多了"的按钮）。

## 9. 本期不做
私信聊天、公开动态流、全站排行榜、按真实身份或学校的公开检索。
