本次评审入口采用自动访客会话：打开网页直接进入产品，不显示注册、登录、昵称开始页或退出按钮。现有页面结构和操作顺序保留。访客可使用产品功能，不能管理用户或修改服务端 AI 配置。

用户要求在 10 月 25 日评审前保持开放，25 日之后继续等待明确指令恢复账号页面；代码没有按日期自动恢复的逻辑。

## 启动与恢复

当前本机检查入口为 http://127.0.0.1:5209/ ，以 TANGO_PORT=5209 运行 npm run dev:auth。该启动器默认自动访客模式；只有显式设置 TANGO_REQUIRE_ACCOUNT=1 才恢复账号流程，操作前等待用户指令。

常规 npm start 仍保留正式账号默认行为。需要演示部署时显式设置 TANGO_DEMO_MODE=1，该模式同样自动进入产品。公网访问还需按部署要求配置 TANGO_PUBLIC_ORIGIN；本机地址不能作为远程评委链接。

演示小组和会话仅存在内存，服务重启后清空；个人记录按访客身份保存在浏览器。访客身份失效后重新生成会话，不代表旧身份数据可恢复。真实模型、语音及外部服务的可用性取决于各自配置，不由免登录模式保证。

## 验证

npm run verify:demo-direct 验证实际演示启动器，覆盖桌面、手机直接进入、刷新、访客身份重新生成、账号表单隐藏、管理接口限制、五种外观和六种语言。

node --test tests/unit/tango-demo-entry.test.mjs 验证演示凭据接口禁用与临时数据存储。
