# 探戈 Done&Go 完成记录界面精简

日期：2026-10-21。此变更覆盖原 V0.2 验收文档中完成表单与用户端评测面板的展示约定。

## 普通用户界面

双击事件气泡，或从事件列表、详情进入完成记录，只显示：

1. 实际用时，分钟，可不填。
2. 是否使用 AI。
3. 使用的模型，可选择或输入；仅勾选使用 AI 后显示，也可留空。

保存后直接回到页面，不追加验收、成本、技能自测、方法实验或收益分配弹窗。之后可以通过“记录用时”补充或修改。

普通回顾页仅显示用户完成记录、填写的用时、AI 使用情况和模型；不显示评测差值、净收益、分项开销、技能测试和证据导出。设置保留基本偏好、AI 整理事项许可、机会提示、个人备份/导入/清空与恢复；不显示调试状态、错误编号、评测导出、服务端点编辑或接口自测。模型帮助去掉实验状态、评测导出与内部规则标签；实际推荐理由、提示词和隐私选择继续保留。

## 记录与兼容性

- 未填用时保存为 `actual: null, timeRecorded: false`，不改成 0 或计划时长，不生成时间测量样本。
- 填写用时是本人自述；不自动标为完成质量已验收，不产生已验证收益或自动预留。内部分析继续区分完成、测量和质量判断。
- 使用的模型保存在白名单清理支持的 `modelName` 字段中；未知型号不强行映射为推荐型号，也不切换当前聊天模型。
- 旧数据继续可读；重新打开旧记录但未修改内容时，不改写原始详细测量和使用历史。
- 修正旧的零分钟记录时，保持有效时间区间；只有尚未使用且已经失效的派生空余时间提示会清理，已作出的预留记录保留。
- 聊天汇总只在已有分享授权内增加数值型 `recordedTime` 汇总；不以此推断模型效果，不发送未授权记录。

## 开发测试封装

原详细完成表单、统计与诊断保留在明确的开发测试路径中，默认不渲染。开发用例在加载页面前显式设置测试钩子 `window.__TANGO_DEVELOPER_UI__`；普通产品没有开关，也不从 URL 或 localStorage 开放该钩子。

该钩子用于本机展示与测试，不是身份认证或服务器授权机制。服务器原有来源、输入和配置保护不变，不能据此主张完成了生产管理员权限系统。

历史评测 UI 用例已显式标注为工程场景；普通用户行为由 `tests/tango/completion-user.spec.ts` 独立验证，避免用开发视图冒充用户验收。

测试只使用模拟记录和受控接口。本轮不验证真实模型当前可用性、费用、母语文化理解或真实手机键盘；不修改现有服务端 API 配置，不发布或推送。
