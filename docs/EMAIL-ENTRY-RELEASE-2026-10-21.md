2026-10-22 本地预览调整：`npm run dev:auth` 默认隐藏注册及登录步骤，自动建立临时访客会话进入首页。体验模式不接收邮箱或密码，真实账号库保留且不被改写，小组数据只保留到服务重启。需要恢复真实账号联调时，在启动进程设置 `TANGO_REQUIRE_ACCOUNT=1`；此开关只适用于本地启动器，正式服务的认证默认值不变。

## 用户链路

进入 App → 邮箱、密码、邮箱验证码注册 → 验证成功后显式登录 → 使用今天、时间之树、回顾、聊天和约定。

未登录时只显示注册或登录入口，深链接也不会开放业务页面。服务器同时验证会话，直接请求业务 API、AI 和语音也不能绕过登录。首页可找回密码，邮件验证码重设密码后旧密码和旧会话失效。

登录后的约定只提供创建或加入，不再要求再次注册。负责人生成随机小组暗号，可复制给多名组员；组员填写同一个暗号即可加入。可忽略大小写、空格和分隔横线。普通成员与只读成员使用不同暗号。新暗号替换同类旧暗号，有效期七天；移除或退出成员会撤销现有暗号，防止用旧暗号重新进入。

暗号采用随机 100 位熵，数据库仅保存摘要。知道暗号可加入相应小组，请仅分享给计划邀请的组员。暗号不会出现在约定列表、历史正文或模型上下文中。

## 数据与安全

- 邮箱验证码单次使用、有效期、最多五次尝试、重发等待，以及 IP/邮箱限流沿用现有服务。注册完成不会自动签发登录 Cookie。
- 会话 Cookie 为 HttpOnly、SameSite=Lax；配置公网 HTTPS 来源或生产模式后启用 Secure。公网 Host、Origin 和端口必须匹配。付费接口有账号与 IP 限流，只有管理员可改全局模型配置。
- 生产和公网模式禁止控制台验证码；生产启动需要显式、持久的会话签名密钥。缺少真实邮箱服务时明确提示，不退回用户名演示账号。
- 个人事件、方法、聊天与隐私偏好按账号隔离保存在当前浏览器。账号、小组、成员、历史与确认保存在服务器 SQLite。个人记录仍不跨设备同步。
- 原有未归属本机记录和旧身份记录保留，没有自动认领、复制或升级成真实邮箱确认。当前真实共享账号库的只读计数为零，未执行身份归属迁移。
- 旧一次性邀请的数据库升级为可重复执行的新增列；旧邀请仍保持一次性。原记录与旧确认不重写。

## 发信配置

在服务器安全环境中选择一种方式。不要把凭据贴到聊天、提交 Git 或放进前端。

| 方式 | 必需环境变量 |
| --- | --- |
| Resend | EMAIL_TRANSPORT=resend、RESEND_API_KEY、MAIL_FROM |
| SMTP | EMAIL_TRANSPORT=smtp、SMTP_HOST、SMTP_PORT、SMTP_USER、SMTP_PASS、MAIL_FROM |

生产还需 NODE_ENV=production、TANGO_PUBLIC_ORIGIN（实际 HTTPS 域名）、TANGO_AUTH_SECRET（至少 32 字节、持久保存）、TANGO_COLLAB_DB（持久目录内的数据库路径）。
