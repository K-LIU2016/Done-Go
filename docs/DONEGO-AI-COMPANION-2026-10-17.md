# Done&Go AI 伙伴接入契约

入口仍为同一个 Done&Go 应用。AI 伙伴通过顶部入口和 `#assistant` 开启，服务今天页、事项模型卡、回顾和时间之树；保留当前配色、时间树和主导航。

## 分层与职责

1. `web/assistant-core.js`：聊天状态白名单、上下文范围、结构化建议校验、事项指纹和用户确认后的纯补丁。
2. `web/assistant-ui.js` / `assistant.css`：聊天、可编辑目标笔记、共享开关、逐条建议与采纳动作；资讯列表和反思入口。
3. `web/index.html`：连接既有时间领域、事项池、本人确认、隐私发送预览和设置。AI 不复制另一套时间账本。
4. `scripts/ai-assistant.mjs`：可选服务器端模型适配；凭据只在服务端配置，OpenAI 兼容和 Anthropic 协议。未配置时明确为本地引导。
5. `scripts/ai-discovery.mjs`：从固定公开 RSS/Atom 获取带日期的 AI 新闻和播客；没有实际来源时显示空或错误，不填充假新闻。

## 对话与个性化

本机聊天与主时间账本分开保存，聊天不会被混入原有主数据导出。默认不会把聊天用于事项建议；用户可明确打开「将聊天用于建议」，选择哪些事项、时间汇总与自己填写的目标笔记进入本次请求，并在发送预览中看到完整内容。

个人目标由用户填写和修改。暂不从随口聊天自动推断稳定人格、心理状态或长期偏好。模型推荐同时参考当前任务、用户明确表达的需求、账户可用性、实际自报的模型任务记录；没有可比样本时保留未知，不能保证所谓精确度。

聊天默认仅保留最近 40 条，单条和笔记有长度限制。接口失败会提示，并允许本地引导；本地文字不会标为真实模型回答。关闭共享只影响后续请求，不能从第三方撤回已经发送的副本。

## 建议的权限

模型只能提出带依据的 `priority/kind/modelId` 建议。建议必须绑定用户此次选中的目标及其指纹；事项被修改、已完成、为个人预留、或本地存储出现冲突时，不得自动套用过期建议。只有用户逐条点击采纳才写入优先级、类别或本人选择的模型候选 `modelPreference`。模型候选在原有能力卡中参与排序，账户不可用时不得成为首选；不把本人选择称为能力排名。草稿记入正式事项和数据导入导出会保留该候选。时间区间、完成状态、实际成本、收益和外部资源不由建议修改。

## 回顾的证据边界

界面中的原始统计由既有时间领域计算，AI 文字单独标为辅助解读。汇总带明确的今天/最近七天窗口和示例/真实模式，包含按事项累加的时间去向、已确认使用的个人预留及任务关联部分。重叠事项可能重复累计，预留不代表已经使用。计划减实际不是不用 AI 的反事实；准备、核对、返工和记录成本不被省略。帮助用户问「哪些事情值得保留、哪些重复操作可以改进、今天的时间是否符合我的选择」，不将休息、陪伴或暂未使用 AI 当作失败。

## 时间之树中的 AI 视野

资讯由用户主动刷新；检索只传预设主题，不传聊天、身份或事项正文。每条显示新闻/播客类型、来源、原文入口、发布日期和检索时间。缓存、部分失败和空结果都有明确状态。网页/播客摘要只是外部数据，不能替用户发出指令或改变事项。

## 配置

两条接入路线：设置中已有的自定义完整 API 地址/型号/本次页面密钥；或专属服务端环境变量 `TANGO_AI_PROVIDER`、`TANGO_AI_URL`、`TANGO_AI_MODEL`、`TANGO_AI_KEY`。服务端固定目标，不接受浏览器传入任意代理目标；配置接口不返回密钥。真实模型调用仍遵守本次发送预览与同意。

新闻聚合与聊天模型是不同能力。当前代码环境中的 Anysearch 工具不等于产品已取得 Anysearch 运行时密钥或服务许可；本轮检索工具返回 403 时不能把失败响应当新闻来源。生产搜索供应商若后续接入，需单独配置凭据与流量预算。

用户可从 [对话入口](http://localhost:5207/#assistant) 进入，再打开 [设置](http://localhost:5207/#settings)：选「自定义接口」，填写完整 API endpoint、实际型号及本次页面密钥，勾选允许，保存。OpenAI 兼容地址以 `/chat/completions` 结尾；Anthropic 使用 `/messages`。点击「测试 AI」仍需确认预览。对话所用的实际型号与事项能力卡中的推荐候选是两个独立设置。

服务端路线只读取专属进程环境变量，不读取历史项目的配置或任何浏览器密钥。当前接口适用于本机个人实测：API 限定 localhost/127.0.0.1 的准确 Host 和同源 Origin。远程公开部署、登录、同步和组织共享仍需独立验收，不由本次本机验证推定。

请求最多附最近十二条历史，并在上下文预算不足时整条省略最旧对话；发送预览始终展示实际请求。显式选中的事项、笔记和当前问题不会为装入预算而悄悄删除；过长会提示减少选择，且不发出请求。客户端提示预算为 55,000 字符和 160 KiB UTF-8，服务端请求体上限 256 KiB，提示上限 60,000 字符和 180 KiB UTF-8。服务端最多两路模型请求；超时和断开会取消上游等待。

公开资讯固定来自 OpenAI News、Hugging Face、Google Research、Latent Space，缓存十五分钟，筛选最近四十五天。音频条目才标为播客；按主题筛选后最多返回三十条。每源响应有大小和超时限制，解析采用前进游标，避免畸形订阅内容拖住整个本地服务。
