# 中文语音与时间之树

验证日期：2026-10-15。适用入口：`node scripts/serve-tango.mjs`，本机 `http://localhost:5207/`。

## 语音链路

原错误「语音服务连不上」对应 Web Speech 的 `network` 事件。静态页原先只调用浏览器识别服务，当前内嵌浏览器无法稳定使用该服务。

现在优先检查本机识别能力。Windows 已安装对应语言的 System.Speech 桌面识别器时，浏览器通过已授权麦克风采集单声道 PCM，转成 16 kHz / 16 bit WAV，并交给同源本机服务转写。当前机器已确认安装中文 `MS-2052-80-DESK`，无需模型下载、API Key 或云端语音服务。

- 点击话筒开始，再点一次停止；检测到说话后停顿 1.6 s 自动停止，最长 30 s。
- 收到首帧音频后才显示「在听」，避免权限或设备尚未准备好时误导用户。
- 转写文字回填输入框，成功解析后直接保存事项并生成 bubble，默认「一般」（`prio: 3`），无需再点「记下」。一次口述支持拆分多项；Windows 返回的 `2:00PM` 等格式先转换成带时段的表达。
- 本机和浏览器语音共用自动创建流程，只提交本次新语音。未发送的手动文字和既有草稿保留；再次点击输入箭头不会重复提交已保存的语音。手动输入继续使用可编辑草稿。
- 新事项与「自己的时间」冲突时，仍由用户选择；取消不会覆盖预留。时间无效的语音项保留为待补时间草稿，不保存无效时段。保存后的识别内容可点击 bubble 修改。
- 拒绝权限不会清空已有文字；离开页面、刷新或取消会释放麦克风。转写失败可以重试。
- 音频仅发送到当前本机服务。服务只接收同源、限定格式和长度的请求，临时 WAV 在转写结束后删除；不写入事项存储，不记录音频或转写日志。
- 未安装相应识别器或未运行该本机服务时，仍尝试浏览器已有语音能力。静态托管页面不自动拥有 Windows 本机转写；当前实测只覆盖 Windows 中文。

另一次「转写未成功」已定位到 Windows 识别循环：多句音频在最后一句返回后会解除音频输入，继续调用 `Recognize()` 抛出 `InvalidOperationException`，导致此前的全部结果被丢弃。循环现在先检查 `AudioFormat`，音频结束后正常返回已识别的内容。约 24 s / 8 句合成中文音频的回归覆盖了这个边界。

真实音频集成测试使用隔离 Edge，将合成中文 WAV 作为麦克风输入，经过实际 Web Audio 采集、停顿自动停止、同源 HTTP、Windows 识别，再验证回填文字、已保存事项和 bubble。原生转写响应不做模拟。合成音频开头加入 1 s 静音，模拟等待话筒就绪再开口。用户自己的实际口述、物理麦克风和不同噪声环境尚未实测，识别文本可能有误字，可从 bubble 修改。

## 时间之树

时间树持续保留选定日期的全部事项，不按已过时段或完成状态过滤。完成记录造成的实际结束时间缩短，不改变树上的原计划时段、分枝位置或照顾提醒分枝；详情同时展示原计划及实际分钟。

状态由独立条件决定：

| 条件 | 图形 |
| --- | --- |
| 未完成，距离开始超过 1 h | 嫩芽 |
| 未完成，距离开始 ≤ 1 h，或计划时间已过 | 花朵 |
| 用户确认完成；自己的时间确认「用到了」 | 果子 |

经过时间不会自动完成任务。时间树每 30 s 更新图形，重新进入前台也会更新；更新只替换树，不重绘输入或关闭详情。当前查看日期固定，跨午夜不会自动切换到空的新一天；日期切换仍由用户操作。刷新后默认查看当天，过去记录可通过日期按钮找回。

## 验证

- Tango 浏览器套件：72 项，71 通过，1 跳过。桌面实际执行合成语音 → Web Audio → 原生转写 → 自动保存事项；手机版跳过相同原生后端的重复集成测试。桌面和 390px 手机覆盖连续录音不重复提交、输入回填、手动文字与草稿保留、冲突取消、失败重试、异步整理取消和浏览器语音回退，以及时间树和原有页面功能。
- `node --test tests/unit/tango-speech.test.mjs tests/unit/tango-time.test.mjs`：16 / 16，包括 Windows 短语音与 8 句长音频的真实离线转写、PCM 编码、无效音频拦截和 AM/PM 时间规范化。
- `node scripts/test-unit.mjs`：610 项，592 通过，18 项既有失败；名称与此前一致，列于 [model-guidance-sources.md](model-guidance-sources.md)。整个仓库并未全部通过。

测试使用隔离浏览器数据，没有在用户浏览器中注入测试事项或录音。
