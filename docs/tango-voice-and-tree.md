# 中文语音与时间之树

验证日期：2026-10-14。适用入口：`node scripts/serve-tango.mjs`，本机 `http://localhost:5207/`。

## 语音链路

原错误「语音服务连不上」对应 Web Speech 的 `network` 事件。静态页原先只调用浏览器识别服务，当前内嵌浏览器无法稳定使用该服务。

现在优先检查本机识别能力。Windows 已安装对应语言的 System.Speech 桌面识别器时，浏览器通过已授权麦克风采集单声道 PCM，转成 16 kHz / 16 bit WAV，并交给同源本机服务转写。当前机器已确认安装中文 `MS-2052-80-DESK`，无需模型下载、API Key 或云端语音服务。

- 点击话筒开始，再点一次停止；检测到说话后停顿 1.6 s 自动停止，最长 30 s。
- 收到首帧音频后才显示「在听」，避免权限或设备尚未准备好时误导用户。
- 成功后进入现有事项整理流程，生成可编辑草稿，由用户确认「记下」。Windows 返回的 `2:00PM` 等时间格式先转换成带时段的表达。
- 拒绝权限不会清空已有文字；离开页面、刷新或取消会释放麦克风。转写失败可以重试。
- 音频仅发送到当前本机服务。服务只接收同源、限定格式和长度的请求，临时 WAV 在转写结束后删除；不写入事项存储，不记录音频或转写日志。
- 未安装相应识别器或未运行该本机服务时，仍尝试浏览器已有语音能力。静态托管页面不自动拥有 Windows 本机转写；当前实测只覆盖 Windows 中文。

已通过真实合成中文音频的离线转写及 HTTP 接口验证，也通过隔离浏览器中的音频采集、草稿生成、拒绝权限和麦克风释放验证。用户自己的实际口述、物理麦克风和不同噪声环境尚未实测；识别结果需在草稿中核对。

## 时间之树

时间树持续保留选定日期的全部事项，不按已过时段或完成状态过滤。完成记录造成的实际结束时间缩短，不改变树上的原计划时段、分枝位置或照顾提醒分枝；详情同时展示原计划及实际分钟。

状态由独立条件决定：

| 条件 | 图形 |
| --- | --- |
| 未完成，距离开始超过 1 h | 嫩芽 |
| 未完成，距离开始 ≤ 1 h，或计划时间已过 | 花朵 |
| 用户确认完成；自己的时间确认「用到了」 | 果子 |

经过时间不会自动完成任务。时间树每 30 s 更新图形，重新进入前台也会更新；更新只替换树，不重绘输入或关闭详情。当前查看日期固定，跨午夜不会自动切换到空的新一天；日期切换仍由用户操作。刷新后默认查看当天，过去记录可通过日期按钮找回。
