# 探戈 Done&Go：时间收益闭环

日期：2026-10-14。适用页面：`web/index.html`。

本文件定义当前网页的产品口径；历史调研与独立工程资料不替代这里的行为说明。

## 已实现模块

| 模块 | 用户收益 | 实现边界 |
| --- | --- | --- |
| 事项池与泡泡 | 记录事项、看见优先级、编辑计划 | AI 指导是可选的事项入口 |
| 全天预算 | 理解安排量与个人预留 | 全日清醒预算减去区间并集，不是剩余时长 |
| 模型能力 | 认识公司、参考型号、用途与设备 | 官方链接；不提供排行榜和固定省时比例 |
| 完成确认 | 留下计划与实际的个人证据 | 输入准备、核对、返工在内的实际分钟；只记录一次 |
| 时间用途 | 把腾出的时间用于用户需要的事 | 持久保存待选项；选择后才预留，冲突由用户确认 |
| 时间树与列表 | 看懂每件事的起止和时长 | 色带映射真实时长，列表提供完整名称 |
| 回顾 | 看见腾出多少、真正用到多少 | 指标、机会列表和日历使用同一个日期范围 |

## 指标约束

`已确认腾出` 是计划与实际分钟的非负差值，不表示这部分时间全部由 AI 带来。AI 与未使用 AI 的完成记录都可进入该指标，是否使用 AI 另行保存。

旧版估计记录、未确认记录、非法分钟、重复事项与日期，不进入确认总量。个人估计需至少两次同类已确认 AI 记录，重复导入不能制造样本量。区间取历史差值比例的观察范围，任务难度仍可能不同。

`已用到自己的时间` 仅统计用户确认用到的个人预留记录。预留本身不算实际收益。时间去向按事项记录累计，重叠事项可能重复统计，页面明确注明这个口径。

## 交互与数据

事项 `完成` 或双击泡泡先打开实际用时表单。确认后保存 `completion` 和 `confirmed:true` 的记录；用时少于计划时，额外保存 `freed.pending`，刷新后仍可决定用途。

原空出时段已经开始或过去时，直接预留按钮禁用。「另选」只允许有效未来时段，时长不超过该次腾出时间。用途通过已有冲突流程添加；取消冲突保留原事项和待选项。

保留已有数据结构、存储键、语音输入、事项解析、导入导出与语言选择。界面不沿用旧产品名称；旧存储值在展示时使用新名称。

## 验证边界

新增纯计算测试和静态网页浏览器测试负责本次行为。独立 React 工程的构建、lint 与原单元测试同时检查；基线失败单独记录，不把构建通过当作完整上线验收。

视觉验收检查真实桌面与手机、明暗主题、空状态、时间列表、完成选项和模型对话框。GitHub 推送验证远程 commit；没有执行生产部署。
