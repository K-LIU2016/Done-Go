# 探戈 Done&Go 首轮用户实测包

适用产品：`web/index.html`，固定使用 http://localhost:5207/#today 。
适用范围：本机、小范围、个人模式。不同主机名、浏览器和浏览器配置文件分别拥有本地数据，`localhost` 与 `127.0.0.1` 的数据也分别存储。开始后固定一个入口。

## 本轮要回答什么

第一场景选择「高校知识工作者对资料初筛/阅读结果的核对」。学生、研究员和教师都可能参与，但本轮不把人群覆盖率当作产品效果。职工场景可另开批次，避免合并不同任务的结果。

检验三个假设：能否完成并理解时间记录；能否在质量达标的前提下记录 AI 的总成本；能否在下一项任务中独立使用并核验模型。用户愿意留下的时间如何使用，由用户自己决定。

## 开始前

1. 在设置页核对版本、真实记录/示例状态、本地存储状态。真实实测不使用示例数据。
2. 导出当前数据留作回退点。固定浏览器与入口；不要使用隐私窗口保存长期实验。
3. 使用允许分享的公开资料，先移除身份、机密和未公开研究内容。AI 初始关闭；启用后每次发送都核对目标和完整提示词。
4. 选择一个真实任务，先写出验收要求和计划时间。观察员在用户操作前不解释「待实测、个人历史、已验收差值」的含义。

## 一次 20–30 分钟任务理解测试

| 脚本 | 观察项目 | 记录方式 |
|---|---|---|
| 记录一个带时间的事项，修改后记下 | 首次成功、误填、放弃、记录成本 | 计时并记错误；不替用户操作 |
| 查看建议、提示词、备选模型和账户状态 | 能否说出候选顺序的依据与限制 | 用户复述原话；不以点击代替理解 |
| 启用模型，查看发送预览，再取消一次 | 是否理解收件服务与取消后的规则降级 | 网络/页面观察与用户复述 |
| 完成事项，先选待核验，再补累计成本和验收 | 是否理解执行、准备、核对、返工与记录成本 | 原始分钟、质量理由、错误/返工 |
| 观察超时或有收益两种结果，主动决定用途 | 是否把差值误读成 AI 因果效果 | 用户解释；允许不预留时间 |
| 查看回顾并导出，再导入和回退 | 是否能找到记录、理解样本和恢复 | 数量与引用抽样对照 |
| 学习任务关闭 AI 后完成一个变式 | 是否独立完成、是否能主动核验 | 结果和验收清单；自述与观察分开 |

首轮招募 8–12 人。预先建议门槛：核心记录到验收完成率 ≥80%；三种证据状态解释正确率 ≥80%；数据丢失和未确认发送均为 0。它们是本轮决策阈值，不是行业标准，也不是已达到的结果。出现严重数据/隐私问题立即暂停该流程并保留脱敏错误编号、版本与复现步骤。

## 质量和时间证据

先检查四项：正确性、完整性、可使用性、来源可核验。未达标选「待核验」或「需返工」；验收后仍将返工与核对成本计入。将观察员计时和用户自报分别保存，缺失值记 UNKNOWN。

计划减实际是计划差值。要研究 AI 的贡献，需要同一用户在可比材料、交付物和验收标准下分别完成 AI/非 AI 任务，记录顺序、模型准确版本、账户地区/套餐、输入规模和外部中断；交叉安排执行顺序。首轮样本只用于探索，不足以建立普遍因果结论。

每条任务至少记录：实验编号、日期、参与者匿名编号、任务类型、基线来源、模型/版本、账户可用性、输入规模、执行/准备/核对/返工/记录用时、质量、是否独立尝试、核验方式和是否允许导出评测。编号对照表由研究者另存，不进入产品匿名导出。

## 后续 cohort 与商业证据

激活定义：同一参与者首次完成「记录 → 本人验收 → 查看回顾」。D7/D30 留存定义：激活后的第 7/30 天，在 ±1 天窗口内至少完成一次新的真实验收；退出、失访、未到观察期分别记录。只有研究者能在用户同意后连接纵向匿名编号；当前单浏览器汇总不提供跨用户留存分母。

4–8 周后再分析任务质量、净时间、独立核验、技能迁移、时间实际用途、放弃原因、付费转化和每活跃用户成本。模型成本、支持成本和付款记录来自真实账单/事件，不从计划时间或演示数据推算。

## 回传材料

优先回传设置中的脱敏诊断、用户主动同意的模型评测、单浏览器汇总，以及观察记录。完整数据导出含私人事项正文，仅供本人备份；分享前另行取得具体同意。所有实验结果回填 `HUMAN-EVIDENCE-BACKLOG.md`，每条附版本、样本、任务脚本、原始证据、反例和排除项。

## 发布和回退

`npm run verify:web` 检查当前产品的数据与服务边界；`npm run verify:ui` 检查桌面/手机主流程；`npm run build` 生成独立 `dist-web/donego-*` 目录及 SHA-256 清单。交付包在自己的目录中运行 `npm start`；运行前先停止已确认属于本项目的旧 5207 服务。

回退使用上一个完整交付目录，保持主机名和端口一致。更换版本前由本人导出数据，旧导出和交付目录均保留。遇到数据结构兼容问题，保留原始内容，先在隔离浏览器中导入验证，再恢复到日常环境。当前容器仅提供可选本机测试路线，未经实际 Docker 构建/运行验证时不能声明该路线通过。
